1. 5 分钟上手

  1. 双击 威肯Log.cmd 启动。命令行窗口会显示地址，浏览器自动打开应用。保持这个命令行窗口开着——关掉它就等于关掉了后台服务。
  2. 顶部有 7 个标签页：今日 / 待办 / 规划 / 收集 / 汇报 / 档案 / 设置。
  3. 先到 设置 添加你的项目（如"梦幻消消乐"）。
  4. 在 今日 顶部输入框敲一条今天做的事，回车——它进入"收件箱"。
  5. 晚上，把收件箱里的条目逐条点 成果 / 待办 / 灵感 / 笔记 归位。
  6. 到 汇报 选"周报"，一键生成文本，复制到飞书/钉钉/邮件。完成！
数据每次改动都会自动保存，无需手动点保存。

2. 两种打开方式

威肯Log 有两种运行模式，顶部横幅会提示你当前所处模式：

方式怎么打开自动备份
本地助手模式（推荐）双击 威肯Log.cmd✅ 自动写文件 + 每日快照
纯文件模式直接双击 app.html❌ 仅存浏览器，需手动导出
如果顶部出现橙色"备份已关闭"横幅，说明你正处于纯文件模式。请改用 威肯Log.cmd 启动以开启自动备份。

3. 日常工作流（白天捕捉 → 晚上整理）

白天：随手在"今日"顶部输入框敲一句就回车，先扔进收件箱，不打断工作。

晚上：逐条整理收件箱，每条选一个去向：

  • 成果：今天真正完成的事 → 记入"今日成果"，可补项目/工作类型/标签，重要的点 ★ 标为亮点。
  • 待办：还没做、以后要做 → 进入"待办"清单。
  • 灵感 / 笔记：想法或参考信息 → 进入"收集"库。
  • 删除：不需要了。

你也可以在"今日成果"里直接敲一条，不必经过收件箱。

4. 待办与结转

  • 在"待办"里新增任务，设置状态、截止日、所属项目、关联目标。
  • 把重要任务点"标为本周重点"，它会出现在"今日"页。
  • 截止日=今天的任务，会显示在"今日 → 今日待办"，勾选即完成。
  • 昨天没做完的任务，第二天"今日"页顶部会提示"未完成 N 项"，点"带入今天"即可；系统会记录"结转次数"，帮你发现一直被拖延的事。

5. 规划四层

"规划"页有四层：本周重点 / 月度 / 季度 / 半年度。每层用 ←/→ 切换周期。

  • 每条目标可写标题、选所属项目、标状态、写"进展备注"（汇报时会用到）。
  • 在"待办"里可把具体任务关联到某个目标，这样就能看到日常在为哪个大目标服务（轻度关联，不强制）。

6. 收集：笔记与灵感

  • 笔记：说明性信息、参考资料。回车即存为笔记。
  • 灵感：点子。先在输入框写内容，点"+ 存为灵感"。
  • 灵感可标状态（原始/孵化中/已转任务/归档），成熟了点"转待办"，一键变成任务。
  • 顶部可按类型筛选、可搜索。

7. 一键汇报

  1. 到"汇报"，选周报或月报，用 ←/→ 选周期。
  2. 系统自动汇总：重点进展（来自规划目标）、具体产出（按项目分组，⭐亮点置顶）、问题与风险、下阶段计划。
  3. 在文本框里手动微调，点"复制到剪贴板"，粘贴到飞书/钉钉/邮件即可。
  4. 展开"自定义模板标题"可改各段落的标题文字。
想让某条产出在汇报里突出？在"今日成果"里点它的 ★，它会带 ⭐ 排在项目最前面。想让某事进入"问题与风险"段？给它打标签 风险。

8. 档案回溯（个人编年史）

"档案"按 月 → 周 → 日 折叠展示你过去的成果、完成的任务、笔记灵感。顶部搜索框可全文检索所有记录。这是你回看成长的地方。

9. 备份与恢复

  • 数据在哪：本地助手模式下，数据是 威肯Log 文件夹里的 weikenlog-data.json；历史快照在 backups/，每天一份。
  • 自动云备份：把整个 威肯Log 文件夹放进 OneDrive 文件夹，OneDrive 会自动把它同步到云端。
  • 手动备份：设置 → 数据备份 → "导出 JSON 备份"。
  • 恢复 / 换机：把 weikenlog-data.json 拷回新机器的 威肯Log 文件夹即可；或用"从 JSON 导入"选择任一备份文件（会覆盖当前数据，导入前有确认）。
  • 从快照回滚：把 backups/ 里某一天的文件复制出来，重命名为 weikenlog-data.json 覆盖即可。

10. 标签体系

三个维度并存：

  • 项目/游戏：结构化下拉，在"设置"里维护，可上色、可归档。
  • 工作类型：策划/研发协调/美术/会议/评审/对外沟通/杂务，可在"设置"里增删。
  • 自由标签：任意关键词，逗号分隔，如 关卡, 数值, 风险。
重命名工作类型不会改写历史记录里已存的类型名；归档只是让它不再出现在下拉里，历史照旧保留。

11. 常见问题与故障排查

  • 浏览器没自动打开？看命令行窗口里的地址（形如 http://127.0.0.1:8787/），手动复制到浏览器。
  • 提示端口被占用？系统会自动换到下一个可用端口，以命令行显示的地址为准。
  • 出现橙色"备份已关闭"？你在用纯文件模式，请改用 威肯Log.cmd 启动。
  • 数据好像没保存？本地助手模式下改动会自动写盘；若右下角弹出"保存失败"，检查磁盘空间/文件夹权限。纯文件模式请记得手动导出。
  • 提示没装 Node？安装 Node.js 后再双击 威肯Log.cmd；临时应急可直接双击 app.html（纯文件模式，记得手动导出备份）。
